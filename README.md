# SoundToTab

Инструмент, который принимает аудиофайл и отдаёт многодорожечный `.gp5`
(табы для гитары и баса, барабанная партия, клавишные) — с возможностью
правки результата вручную.

## Стратегия

Не обучаем модели с нуля. Собираем продукт вокруг готовых open-source моделей:

```
mp3 → Demucs (разделение на стемы)
    → транскрипция по инструментам (basic-pitch / своя модель барабанов)
    → постобработка (квантизация, темп, фильтр коротких нот)
    → MIDI → (струна, лад) для гитары/баса
    → .gp5 / MusicXML
```

Своя первая модель — классификатор барабанов (kick / snare / hi-hat) —
появляется только на 5–6 неделе, когда пайплайн уже работает.

## Железо

| Машина | Роль |
|---|---|
| Ноутбук, Arch, AMD iGPU | разработка, тесты, librosa, экспорт (CPU) |
| ПК, RTX 3050 8 GB | обучение, Demucs, инференс |

Код пишется так, чтобы работать на обеих:
`device = "cuda" if torch.cuda.is_available() else "cpu"`.

```
SoundToTab/
├── PLAN.md              # учебный и рабочий план на 12 недель
├── SETUP-ARCH.md        # настройка окружения на ноуте и на ПК
├── README.md
├── pyproject.toml
├── .gitignore
├── src/song2tab/
│   ├── cli.py           # song2tab song.mp3 -o out.gp5
│   ├── audio.py         # загрузка, ресемплинг, mel
│   ├── separate.py      # Demucs
│   ├── transcribe/
│   │   ├── pitch.py     # basic-pitch
│   │   └── drums.py     # своя модель
│   ├── postprocess.py   # квантизация, темп, фильтрация
│   ├── tab.py           # MIDI → (струна, лад)
│   └── export.py        # .gp5
├── tests/
├── notebooks/
├── data/                # в .gitignore
└── PyTorch_ML/          # старый учебный репозиторий, референс
```

## Статус

Подготовка. Активный план — в [PLAN.md](PLAN.md), настройка окружения —
в [SETUP-ARCH.md](SETUP-ARCH.md).

## Правовая оговорка

Транскрипции чужих песен — производные произведения. Для личного
использования и локального инструмента это одна история, для публичного
SaaS — другая, там нужны лицензии. Учитывать до запуска коммерции.
